# 评论图片与缓存

B站采集保留根评论和楼中楼的图片链接、尺寸及所属评论版本。卡片显示缩略图，展开详情后点击缩略图查看原图。楼中楼变化和历史版本均使用对应版本的图片引用。图片新增、移除或替换会产生内容变化。

图片在需要展示或决策升级时下载到服务器私有缓存。仅查看缩略图不会保留原图文件。多个评论使用相同链接时共用缓存。

| 全局配置 | 默认值 |
| --- | --- |
| 图片缓存总上限 | 256 MiB |
| 原图连续未使用保留期限 | 7天 |
| 缩略图连续未使用保留期限 | 30天 |
| 磁盘预留空间 | 128 MiB |

缓存到期会清理。达到总上限时，先淘汰最久未使用的原图，再淘汰缩略图。正在下载、生成或读取图片的操作会完成后再执行清理；下载临时文件也计入容量预算，已缓存文件按实际分配的磁盘空间计量，并最多保留4096个文件，避免大量小图占用过多文件系统空间。后台每10分钟检查期限，访问图片时也检查。单张下载最多10 MiB，缓存预算更小时按剩余可用预算限制。低于磁盘预留空间时停止新增缓存。

在**全局配置 → 图片缓存**查看占用或清空缓存。清理保留评论、图片链接与分析历史，再次查看时尝试重新下载。原链接不可用且没有缓存时会显示失败提示。浏览器当前已显示的图片可保持到离开页面，清理释放的是服务器缓存。

Jev 初步判断继续只接收文字与图片元数据。含图评论必须进入决策升级，由已配置的生成／分析模型结合实际图片判断；纯文字评论保持原有置信度分流。升级会话输入包含根评论及楼中楼图片、所属评论和版本清单。图片按比例缩放到最长边2048像素，最多20张、编码合计最多10MiB，不会静默省略超限图片。图片失败、超限或模型未明确声明支持看图时转人工。后续拟稿和监督仅参考升级判断的文字依据，不重复输入图片；手动会话保持文字背景。

升级图片通过 DSH 标准附件接口进入真实会话，随宿主会话历史保留。**256 MiB 上限及7／30天清理只管理本插件的网页／下载缓存，不涵盖 DSH 会话附件。**清空图片缓存不会删除已经输入模型的会话附件；同一规范化图片由宿主按内容去重。

图片文件通过宿主认证后的接口读取。下载只允许B站图片CDN，拒绝重定向，不向图片服务器发送账号Cookie。
