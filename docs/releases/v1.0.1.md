# 看点什么 v1.0.1

修复慢网络下历史学习批次一直显示“正在加载”的问题。

## 修复内容

- 学习记录列表与批次详情等待当前请求完成后再安排下一次刷新，耗时超过刷新间隔的响应也能正常显示。
- 同样修复总览、来源列表、内容详情、工作记录、草稿和凭据状态等共享轮询页面，避免重复请求积压及成功响应被后续请求丢弃。
- 切换页面、分页或刷新配置时取消旧请求，迟到结果不会覆盖当前页面；离开页面后停止轮询。
- 评价、批次详情、总览、来源编辑、内容详情与草稿请求失败时不再继续显示加载文案；评价和来源编辑可直接重试。
- 发起学习或保存来源后切换到其他页面，较晚返回的结果不会强行跳回旧页面或清除正在编辑的评价。
- 添加来源时快速切换内容类型再切回，已取消的元信息请求可以重新发起，名称、简介等自动填写不再静默停止。

## 升级说明

依赖版本与 DSH `0.2.1` 系列兼容范围保持不变。本次不涉及数据库迁移，继续使用 SQLite schema 6，已有学习批次、提案、评价及真实会话历史保留。

按[安装与账号配置](../INSTALLATION.md)安装 `dsh-message-console-1.0.1.tgz`，重新打开或刷新看点什么页面以加载新版界面。升级前备份现有插件、配置和数据，并等待在途工作结束。
